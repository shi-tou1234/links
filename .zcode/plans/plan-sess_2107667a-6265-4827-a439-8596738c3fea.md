
## 实施计划：EE 链接导航项目 UI 重构

### 目标
将 preview.html 中的新 UI 设计正式应用到项目文件中，替换图标，重写 README，清理预览文件，提交 GitHub。

### 方案选择：重写现有文件结构（保持分离架构）
preview.html 是一个 53KB 的单文件，内联了所有 CSS 和 JS。直接用它替换 index.html 会丢失分离架构的优势。选择**重写现有文件**以保持可维护性。

### 步骤

#### 1. 重写 CSS 文件（6个文件）
基于 preview.html 的内联样式，拆分回各 CSS 文件：

| 文件 | 内容 |
|------|------|
| `variables.css` | 删除（不再需要主题变量，全部硬编码暗色值） |
| `base.css` | 重写：基础重置 + body 暗色背景 + 字体 + 无障碍 |
| `layout.css` | 重写：mesh 渐变背景 + 噪点纹理 + 鼠标光晕 + 滚动进度条 + 透明导航栏 + Hero + Footer |
| `components.css` | 重写：搜索框 + 筛选 chip + 空状态（删除主题切换按钮样式） |
| `cards.css` | 重写：玻璃拟态卡片 + 彩虹外发光悬停 + 图标旋转 + 箭头发光 + 光泽扫过 |
| `masonry.css` | 保留现有结构，微调响应式断点 |
| `main.css` | 更新 @import 列表（删除 variables.css） |

#### 2. 重写 index.html
- 更新结构：移除主题切换按钮，Hero 区域使用新布局
- 品牌图标：替换 "EE" 文字为 SVG 芯片/电路图标
- 保留所有功能区域：搜索、筛选、卡片网格、骨架屏、回到顶部

#### 3. 更新 JS 文件
| 文件 | 改动 |
|------|------|
| `data.js` | 不变（46个链接 + 辅助函数） |
| `render.js` | 删除 `card.style.background = gradient` 行（让 CSS 玻璃拟态生效） |
| `filter.js` | 不变 |
| `theme.js` | 简化为仅 `applyTheme()` 设置 `data-theme="dark"`，删除 toggleTheme |
| `effects.js` | 粒子颜色固定为亮色，其余不变 |
| `main.js` | 删除 `applyTheme` 调用（或保留简化版） |

#### 4. SVG 图标设计
设计一个简洁的芯片/电路 SVG 图标（约 32x32），替代 "EE" 文字：
- 圆角方形外框
- 内部电路走线 + 中心节点
- 粉紫渐变填充

#### 5. 重写 README.md
- 新标题和描述
- 更新特性列表（暗色主题、mesh 渐变、玻璃拟态、彩虹悬停等）
- 使用说明
- 项目结构

#### 6. 清理
- 删除 `preview.html`
- 确认 `.gitignore` 包含 `.mimosa/`

#### 7. Git 提交
- `git add -A`
- 提交信息：`refactor(ui): redesign with mesh gradient glassmorphism dark theme`
- `git push`
