# links · 电子信息常用网页链接指南

面向电子信息学生的常用站点索引，覆盖芯片选型、EDA 工具、竞赛资源和求职准备。

## 特性

- **Mesh 渐变背景** — 8 层径向渐变叠加，带模糊和缓慢旋转动画，营造深邃流动的视觉效果
- **玻璃拟态卡片** — 半透明背景 + `backdrop-filter` 磨砂效果，透出底层渐变
- **炫酷悬停效果** — 彩虹渐变外发光边框、卡片抬升放大、图标旋转上浮、箭头粉色发光、标签微浮
- **噪点纹理** — SVG fractalNoise 叠加层，增加画面质感
- **鼠标光晕** — 500px 粉色径向渐变跟随鼠标移动
- **滚动进度条** — 顶部 2px 彩色渐变进度指示
- **分类筛选** — 8 个分类 + 收藏筛选，带计数徽章
- **关键词搜索** — 实时匹配站点名称、描述和标签
- **收藏系统** — 星标收藏，localStorage 持久化
- **骨架屏加载** — 6 张骨架卡片 shimmer 动画
- **滚动渐入** — IntersectionObserver 驱动的卡片入场动画
- **打字机标语** — 循环展示使用提示
- **粒子背景** — Canvas 绘制的稀疏浮动粒子
- **响应式布局** — 桌面 3 列 → 平板 2 列 → 手机单列，筛选横向滚动
- **无障碍** — `prefers-reduced-motion` 支持、`:focus-visible`、`aria-label`

## 使用

直接用浏览器打开 `index.html` 即可，无构建依赖。

## 项目结构

```
├── index.html          # 主页面
├── css/
│   ├── main.css        # @import 入口
│   ├── base.css        # 基础重置 + 字体 + 无障碍
│   ├── layout.css      # 背景 + 导航栏 + Hero + 布局
│   ├── components.css  # 搜索框 + 筛选 chip + 空状态
│   ├── cards.css       # 玻璃拟态卡片 + 悬停效果
│   └── masonry.css     # 瀑布流布局 + 响应式
└── js/
    ├── data.js         # 46 个精选站点数据
    ├── render.js       # 卡片构建 + 骨架屏 + 统计
    ├── filter.js       # 分类筛选 + 搜索 + 收藏筛选
    ├── theme.js        # 深色模式初始化
    ├── effects.js      # 粒子 + 打字机 + 滚动动画
    └── main.js         # 启动编排
```
